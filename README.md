# Лабораторная работа 3. Мультиагентное RL для разметки музыкального каталога

Тема ВКР: *Разработка системы автоматической разметки музыкального каталога по типу фронт-вокала для задач поиска и рекомендаций.*
Продолжение: [ЛР1](https://github.com/kater1nart/lab1_vocal_llm), [ЛР2](https://github.com/kater1nart/lab2_multimodal_vocal).

**Среда** (`src/env.py`): поток из 50 треков, 4 кооперативных агента — эксперты по тексту, звуковому ряду и спектрограмме
(голос за класс / воздержаться) и координатор (автометка / модератор, бюджет 15 проверок). Награда: +1 верная автометка,
−3 ошибка, −0,4 проверка, −0,5 без метки, −1 нарушение бюджета.

## Результаты (MTAT test, 5 seed × 256 эпизодов, ценность разметки за 50 треков)

| Политика | Ценность [95% ДИ] | Jamendo 2010–2017 |
|---|---|---|
| Равные веса + порог (baseline) | **8.58** | −19.44 |
| PPO, 1 агент (baseline) | 8.50 [7.23, 9.76] | **−8.44** |
| MAPPO | 2.79 [2.20, 3.37] | −15.68 |
| QMIX | 2.23 [1.09, 3.37] | −18.39 |
| VDN | 1.62 | −15.04 |
| IPPO | 1.41 | −14.99 |
| IQL | 1.22 | −15.92 |
| MAA2C | 0.23 | −19.81 |
| MADDPG | −1.85 | −18.15 |
| COMA | −38.4 (вырожденная политика) | −38.4 |

Отчёт: `report/Отчет_ЛР3.docx`.

## Воспроизведение
```bash
uv venv -p 3.11 .venv && uv pip install -p .venv -r requirements.txt
# data/stream.parquet строится из ЛР2: ../../2/lab2_multimodal_vocal/.venv/bin/python src/make_stream.py
cd src && ../.venv/bin/python run_all.py && ../.venv/bin/python analyze.py && cd .. && .venv/bin/python src/build_report.py
```
Бюджет: 600 итераций × 64 среды × 50 шагов на запуск, seed 0–4.
